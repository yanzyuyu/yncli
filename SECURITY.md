# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within **YNCLI**, please do not open a public issue.

Instead, please send an email to **stockrii800@gmail.com** or report it via private GitHub Security Advisory. We will review and respond to the report within 48 hours.
